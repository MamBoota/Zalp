# 📺 TV_FIX_VPN — Прозрачный VPN для Smart TV

Надстройка над **Mihomo**, которая перехватывает трафик Smart TV по MAC-адресу и прозрачно направляет его через VPN-прокси. Если VPN падает — трафик автоматически возвращается к **Zalp** (fallback).

Решение построено на **TPROXY** + **iptables** и работает без настройки прокси на самом телевизоре.

---

## ✨ Возможности

- 🎯 Прозрачный перехват трафика ТВ по MAC-адресу (без настроек на самом TV)
- 🔒 Блокировка QUIC и DoH (UDP 443, TCP/UDP 853) — чтобы ТВ не обходил прокси
- 🌐 Перенаправление DNS-запросов ТВ на внутренний резолвер Mihomo (порт 1053)
- 🔄 Автоматический fallback на Zalp при падении VPN
- 👁️ Watchdog в `cron` — проверка каждые 3 минуты
- 📊 Встроенная диагностика (`fix test`) — статус, порты, правила, маршруты
- 📝 Логирование всех событий в `/var/log/tv_fix_vpn.log`
- 🧹 Полная очистка при удалении — система возвращается в исходное состояние

---

## 📋 Требования

- **Установленный и работающий Mihomo** (см. [install_mihomo.sh](install_mihomo.sh))
- Linux с поддержкой `iptables`, `TPROXY`, `ip rule`
- `root`-права (или `sudo`)
- Утилиты: `bash`, `curl`, `iptables`, `ss`, `ip`, `systemctl`, `cron`
- Smart TV подключён к той же сети (LAN), что и сервер

---

## ⚙️ Настройка перед установкой

Перед запуском скрипта **обязательно** откройте `install-tv-fix-vpn.sh` и пропишите MAC-адреса своих телевизоров:

```bash
TV_MAC_1="00:00:00:00:00:00"   # LG WebOS пример
TV_MAC_2="AA:BB:CC:DD:EE:FF"   # Samsung Tizen 1 пример
TV_MAC_3="11:22:33:44:55:66"   # Samsung Tizen 2 пример
```

> 💡 MAC-адрес можно узнать в веб-интерфейсе роутера или в настройках самого ТВ (Сеть → Состояние → MAC-адрес).

## 📥 Установка

```bash
# Скачиваем установочный скрипт
wget https://raw.githubusercontent.com/<ваш-репо>/main/install-tv-fix-vpn.sh

# Делаем исполняемым и запускаем
chmod +x install-tv-fix-vpn.sh
sudo ./install-tv-fix-vpn.sh
```

Скрипт выполнит 6 этапов:
1. Очистка старых версий TV_FIX_VPN
2. Добавление `tproxy-port: 7892` в конфиг Mihomo и его перезапуск
3. Создание команды `fix` в `/usr/local/bin/fix`
4. Установка watchdog в `cron` (каждые 3 минуты)
5. Первичный запуск (`fix start`)
6. Диагностика (`fix test`)

## 🎮 Команды управления

После установки доступна глобальная команда `fix`:

| Команда        | Описание                                           |
|----------------|----------------------------------------------------|
| `fix start`    | 🟢 Включить перехват трафика ТВ через VPN          |
| `fix stop`     | 🔴 Отключить перехват, вернуть трафик к Zalp       |
| `fix restart`  | 🔄 Перезапустить патч (stop → start)               |
| `fix test`     | 🔍 Полная диагностика                              |
| `fix watchdog` | 👁️ Внутренняя команда для cron (авто-fallback)    |

### Пример использования

```bash
# Включить VPN для ТВ
sudo fix start

# Проверить статус
sudo fix test
```

## 🧩 Как это работает

```
┌──────────────┐     ┌─────────────────────────────────────────────┐
│   Smart TV   │────▶│              Linux-сервер                   │
│  (по MAC)    │     │                                             │
└──────────────┘     │  iptables PREROUTING                        │
                     │      ↓                                      │
                     │  TV_VPN_FIX (mangle)                        │
                     │      ├─ DROP QUIC/DoH (чтобы не обходили)   │
                     │      ├─ TPROXY → 127.0.0.1:7892 (Mihomo)    │
                     │      └─ ACCEPT (не отдаём Zalp/NFQWS)       │
                     │                                             │
                     │  TV_VPN_FIX (nat)                           │
                     │      └─ REDIRECT DNS :53 → :1053 (Mihomo)   │
                     │                                             │
                     │  Mihomo (TPROXY mode)                       │
                     │      ↓                                      │
                     │  VPN-сервер (из подписки)                   │
                     └─────────────────────────────────────────────┘
```

**Ключевые моменты:**
- **TPROXY** — прозрачное проксирование на уровне ядра, без NAT (сохраняются оригинальные IP)
- **fwmark 0x1** — метка для policy routing, чтобы TPROXY-пакеты возвращались в Mihomo
- **DROP QUIC/DoH** — блокируем UDP 443 и TCP/UDP 853, иначе ТВ будет шифровать DNS в обход прокси
- **Приоритет над Zalp** — цепочка `TV_VPN_FIX` вставляется первой в `PREROUTING`

---

## 🔄 Автоматический fallback

Watchdog в `cron` каждые 3 минуты:
- Проверяет, отвечает ли Mihomo (`curl` через прокси)
- Если Mihomo **упал** → `fix stop` → трафик ТВ возвращается к Zalp
- Если Mihomo **восстановился** → `fix start` → трафик снова идёт через VPN

Это гарантирует, что ТВ **никогда не останется без интернета**, даже если VPN временно недоступен.

## 🗑️ Полное удаление

```bash
wget https://raw.githubusercontent.com/<ваш-репо>/main/uninstall-tv-fix-vpn.sh
chmod +x uninstall-tv-fix-vpn.sh
sudo ./uninstall-tv-fix-vpn.sh
```

Скрипт удалит:
- Правила iptables и цепочки `TV_VPN_FIX` (nat + mangle)
- Маршруты TPROXY (`ip rule` и `table 100`)
- Команду `fix` и вспомогательные скрипты
- Задачу watchdog из `cron`
- Лог-файл `/var/log/tv_fix_vpn.log`

> ⚠️ **Mihomo при этом не удаляется** — он продолжает работать для ручного использования.  
> Чтобы удалить и Mihomo, запустите отдельно `uninstall_mihomo.sh`.

## 🐛 Troubleshooting

| Проблема                                      | Решение                                                    |
|-----------------------------------------------|------------------------------------------------------------|
| `fix test` показывает ❌ Порт 7892 не слушается | Проверьте, что `tproxy-port: 7892` есть в `/etc/mihomo/config.yaml` и перезапустите: `sudo systemctl restart mihomo` |
| Трафик ТВ не идёт через VPN                   | Убедитесь, что MAC-адрес ТВ совпадает с прописанным в скрипте |
| ТВ не грузит YouTube/приложения               | Проверьте, что QUIC/DoH блокируются (должны быть правила `DROP` в `fix test`) |
| После `fix start` пропал интернет у ТВ        | Проверьте, что Mihomo работает: `sudo mihomo-test`         |
| Watchdog не срабатывает                       | Проверьте cron: `sudo crontab -l`                          |

### Просмотр логов в реальном времени
```bash
sudo tail -f /var/log/tv_fix_vpn.log
```

### Ручная проверка правил iptables
```bash
sudo iptables -t mangle -L TV_VPN_FIX -n -v
sudo iptables -t nat -L TV_VPN_FIX -n -v
```

### Проверка маршрутов TPROXY
```bash
ip rule list | grep 0x1
ip route show table 100
```
