# 🛡️ Zalp — Умный обход DPI для дома

**Zalp** — это комплексная система обхода DPI-блокировок на базе [zapret](https://github.com/bol-van/zapret), оптимизированная для домашнего сервера-роутера. Включает автоматическое самолечение, мониторинг, консоль управления и горячую замену без разрыва интернета.

## ✨ Возможности

- 🚀 **Обход DPI** для YouTube, Instagram, Facebook, Threads и других сервисов
- 🩺 **Автоматическое самолечение** (Zalp Doctor) каждые 5 минут
- 🔥 **Горячая замена** — переустановка без разрыва интернета
- 🎛️ **Консоль управления** (`zalp`) — все функции в одном меню
- 📦 **Самообновление** — следит за новыми версиями на GitHub и обновляется в один пункт меню
- 📊 **Расширенная диагностика** с проверкой всех компонентов
- 🔄 **Автозапуск** через systemd + cron
- 🌐 **Поддержка IPv4/IPv6** для консолей (Xbox, PlayStation)

## 🚀 Быстрый старт

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/MamBoota/Zalp.git
cd Zalp

# Запускаем установку
sudo ./install.sh
```

Установщик автоматически:
1. Проверит наличие предыдущей установки
2. Установит все зависимости
3. Соберёт движок из исходников
4. Настроит автозапуск
5. Установит консоль управления `zalp`

### Переустановка (горячая замена)

```bash
sudo ./restore.sh
```

**Важно:** `restore.sh` полностью удаляет Zalp и переустанавливает его **без разрыва интернета**. Клиенты не заметят перебоев.

## 🎛️ Консоль управления

```bash
zalp
```

Команда сама запросит sudo. Открывается панель с версией продукта, статусом компонентов и меню:

| Пункт | Действие |
|-------|----------|
| 1 | Статус системы |
| 2 | Полная диагностика |
| 3 | Запустить обход |
| 4 | Остановить обход |
| 5 | Безопасный перезапуск |
| 6 | Doctor (ручной запуск) |
| 7 | Логи Doctor |
| 8 | Проверить обновления |
| 9 | Установить обновление |
| 0 | Выход |

Если на GitHub вышла новая версия — в панели загорится жёлтый аларм с номером доступной версии.

## 📦 Обновление продукта

Консоль сама следит за обновлениями:

- Текущая версия хранится в `/opt/zalp/VERSION`
- При старте консоли проверяются теги/релизы репозитория на GitHub (кэш проверки — 24 часа)
- При обнаружении новой версии в панели появляется аларм
- Пункт **9** скачивает новые `install.sh`, `restore.sh`, `zalp-console.sh` и запускает горячую замену через `restore.sh` — интернет не прерывается

### Выпуск новой версии (для сопровождающего)

```bash
# 1. Поднять версию в install.sh (баннер и файл VERSION)
# 2. Закоммитить изменения
git add -A && git commit -m "v4.2: описание изменений"
# 3. Создать тег и запушить
git tag v4.2
git push origin HEAD --tags
```

После этого все установленные копии увидят аларм об обновлении в консоли.

| Команда | Описание |
|---------|----------|
| `sudo zalp` | Консоль управления (меню) |
| `sudo zalp-start` | Запустить обход DPI |
| `sudo zalp-stop` | Остановить обход DPI |
| `sudo zalp-restart` | Безопасный перезапуск (с проверкой интернета) |
| `sudo zalp-status` | Краткий статус системы |

| `sudo zalp-restore` | Восстановление конфигурации |

## 🩺 Система самолечения (Zalp Doctor)

**Zalp Doctor** автоматически проверяет систему каждые 5 минут:

- ✅ Статус сервиса `nfqws`
- ✅ Включён ли IP forwarding
- ✅ Отсутствие дубликатов правил NAT
- ✅ Наличие правил NFQUEUE
- ✅ Доступность интернета
- ✅ Автоматическое переподключение сети при проблемах

Лог работы: `/var/log/zalp-doctor.log`

## 🔧 Конфигурация

### Списки доменов

Файлы конфигурации находятся в `/opt/zalp/`:

- `domains.txt` — список доменов для обхода DPI
- `domains-exclude.txt` — исключения (корпоративные сервисы)

### Стратегия обхода

Текущая стратегия в `/etc/systemd/system/nfqws.service`:

```bash
--dpi-desync=fakedsplit
--dpi-desync-split-pos=1
--dpi-desync-autottl
--dpi-desync-fooling=badseq
--dpi-desync-repeats=2
```

Оптимизирована для стриминга видео (4K, Shorts, Reels) с минимальными задержками.

## 🔍 Подбор стратегии

Если обход перестал работать, используйте встроенный инструмент `blockcheck.sh`:

```bash
cd /opt/zalp
sudo ./blockcheck.sh
```

Следуйте инструкциям:
1. Введите домен для теста (например, `www.youtube.com`)
2. Выберите `standard` режим
3. Дождитесь окончания (5-10 минут)
4. Найдите строку `--- WORKING strategy for nfqws: ...`
5. Обновите параметры в `/etc/systemd/system/nfqws.service`
6. Перезапустите: `sudo zalp-restart`

## 📋 Требования

- **ОС:** Ubuntu 20.04+ / Debian 11+
- **Права:** root (sudo)
- **Сеть:** сервер должен работать как роутер (IP forwarding)
- **Зависимости:** устанавливаются автоматически

## 🌐 Настройка клиентов

Чтобы клиенты (телефоны, ноутбуки, ТВ) использовали Zalp:

1. Подключите их к Wi-Fi/Ethernet вашего сервера
2. В настройках сети укажите:
   - **Шлюз (Gateway):** IP вашего сервера
   - **DNS:** IP вашего сервера (или любой публичный DNS)

Пример для роутера:
```
Шлюз: 192.168.1.50
DNS: 192.168.1.50
```

## 🎮 Поддержка консолей (Xbox, PlayStation)

Для Xbox и PlayStation рекомендуется настроить **прямое подключение** к основному роутеру (шлюз = основной роутер), чтобы избежать Double NAT.

## 🐛 Troubleshooting

### Обход не работает

1. Откройте консоль: `sudo zalp` → пункт 2 (диагностика)
2. Проверьте статус: `sudo zalp-status`
3. Проверьте логи: `tail -f /var/log/zalp-doctor.log`
4. Попробуйте перезапуск: `sudo zalp-restart`
5. Если не помогло — запустите `blockcheck.sh` для подбора стратегии

### Нет интернета после установки

1. Остановите обход: `sudo zalp-stop`
2. Проверьте интернет
3. Если работает — проблема в стратегии обхода
4. Запустите `blockcheck.sh` для подбора рабочей стратегии

### Переустановка

```bash
sudo ./restore.sh
```

Это полностью очистит систему и переустановит Zalp без разрыва интернета.
