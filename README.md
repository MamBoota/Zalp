# 🛡️ Zalp v5.0 — Умный обход DPI и управление сетью

**Zalp** — это комплексная, модульная система обхода DPI-блокировок и управления сетевым трафиком на базе [zapret](https://github.com/bol-van/zapret), оптимизированная для домашнего сервера или роутера. В версии 5.0 система объединяет в себе обход DPI, прозрачный прокси (Mihomo), исправление маршрутизации для Smart TV и встроенную диагностику.

## ✨ Возможности

- 🚀 **Обход DPI**: YouTube, Instagram, Facebook, Threads и другие сервисы.
- 🩺 **Zalp Doctor**: Автоматическое самолечение и мониторинг каждые 5 минут.
- 🔄 **Горячая замена**: Переустановка и обновление без разрыва интернета.
- 🎛️ **Единая консоль `zalp`**: Управление всеми модулями из одного меню.
- 🌐 **Модуль Mihomo**: Встроенная поддержка прозрачного прокси (VLESS, Trojan, Shadowsocks и др.).
- 📺 **TV Fix VPN**: Автоматический прозрачный VPN для Smart TV (LG, Samsung) без настройки на самом телевизоре.
- 🧪 **Встроенный Blockcheck**: Автоматический подбор рабочих стратегий обхода для вашего провайдера.
- 📦 **Самообновление**: Следит за релизами на GitHub и обновляется в один клик.

## 🚀 Быстрый старт

### Установка

```bash
git clone https://github.com/MamBoota/Zalp.git
cd Zalp
sudo ./install.sh
```

Установщик предложит настроить базовый обход DPI, а также опционально установить **Mihomo** и **TV Fix**.

### Единая консоль управления

Просто введите в терминале:

```bash
sudo zalp
```

Откроется интерактивное меню со статусом всех систем, управлением DPI, прокси, ТВ и диагностикой.

### Команды управления

Все команды теперь объединены под одним интерфейсом `zalp`:

| Команда | Описание |
| --- | --- |
| `sudo zalp` | Интерактивная консоль управления |
| `sudo zalp start` | Запустить обход DPI |
| `sudo zalp stop` | Остановить обход DPI |
| `sudo zalp restart` | Безопасный перезапуск (с проверкой сети) |
| `sudo zalp status` | Краткий статус всех модулей |
| `sudo zalp doctor` | Ручной запуск самолечения |
| `sudo zalp mihomo` | Меню управления прокси Mihomo |
| `sudo zalp tvfix` | Меню управления прозрачным VPN для ТВ |
| `sudo zalp test` | Запуск встроенного blockcheck.sh |
| `sudo zalp restore` | Полная очистка и горячая переустановка |

## 🌐 Модуль Mihomo (прозрачный прокси)

Mihomo — это прокси-ядро (Clash.Meta), которое позволяет использовать подписки VLESS/Trojan/Shadowsocks как прозрачный прокси.

### Установка

При установке Zalp вам будет предложено установить Mihomo. Либо вручную:

```bash
sudo ./mihomo/install_mihomo.sh
```

Скрипт запросит URL подписки от вашего VPN-провайдера.

### Команды

| Команда | Описание |
| --- | --- |
| `mihomo-start` | Запуск сервиса |
| `mihomo-stop` | Остановка |
| `mihomo-restart` | Перезапуск |
| `mihomo-test` | Диагностика (статус, активный узел, HTTP/HTTPS, внешний IP) |

### Watchdog

Mihomo автоматически перезапускается каждые 5 минут при падении (cron).

## 📺 Модуль TV Fix VPN (прозрачный VPN для Smart TV)

TV Fix — это надстройка над Mihomo, которая перехватывает трафик Smart TV по MAC-адресу и прозрачно направляет его через VPN.

### Установка

```bash
sudo ./TV_FIX_VPN/install-tv-fix-vpn.sh
```

⚠️ **Важно**: Перед установкой откройте `install-tv-fix-vpn.sh` и пропишите MAC-адреса своих телевизоров:

```bash
TV_MAC_1="74:E6:B8:06:CD:8A"   # LG WebOS
TV_MAC_2=""                     # Samsung Tizen 1
TV_MAC_3=""                     # Samsung Tizen 2
```

### Как это работает

- Перехватывает трафик ТВ по MAC-адресу (без настроек на самом TV)
- Блокирует QUIC и DoH (UDP 443, TCP/UDP 853) — чтобы ТВ не обходил прокси
- Перенаправляет DNS-запросы ТВ на внутренний резолвер Mihomo
- Автоматический fallback на Zalp при падении VPN
- Watchdog проверяет каждые 3 минуты

### Команды

| Команда | Описание |
| --- | --- |
| `fix start` | Включить перехват ТВ через VPN |
| `fix stop` | Отключить перехват, вернуть трафик к Zalp |
| `fix restart` | Перезапустить патч |
| `fix test` | Полная диагностика |

## 🧪 Встроенный Blockcheck

Если обход перестал работать, используйте встроенный инструмент:

```bash
sudo zalp test
# или напрямую:
cd /opt/zalp
sudo ./blockcheck.sh
```

Следуйте инструкциям:

1. Введите домен для теста (например, `www.youtube.com`)
2. Выберите `standard` режим
3. Дождитесь окончания (5-10 минут)
4. Найдите строку `--- WORKING strategy for nfqws: ...`
5. Обновите параметры в `/etc/systemd/system/nfqws.service`
6. Перезапустите: `sudo zalp restart`

## 📦 Обновление продукта

Консоль сама следит за обновлениями:

- Текущая версия хранится в `/opt/zalp/VERSION`
- При старте консоли проверяются теги/релизы репозитория на GitHub (кэш проверки — 24 часа)
- При обнаружении новой версии в панели появляется аларм
- Пункт **9** скачивает новые `install.sh`, `restore.sh`, `uninstall.sh`, `zalp-console.sh` и запускает горячую замену через `restore.sh` — интернет не прерывается

### Выпуск новой версии (для сопровождающего)

```bash
# 1. Поднять версию в install.sh (баннер и файл VERSION)
# 2. Закоммитить изменения
git add -A && git commit -m "v5.1: описание изменений"
# 3. Создать тег и запушить
git tag v5.1
git push origin HEAD --tags
```

После этого все установленные копии увидят аларм об обновлении в консоли.

## 🔧 Конфигурация

### Списки доменов

Файлы конфигурации находятся в `/opt/zalp/`:

- `domains.txt` — список доменов для обхода DPI
- `domains-exclude.txt` — исключения (корпоративные сервисы)

### Стратегия обхода

Текущая стратегия в `/etc/systemd/system/nfqws.service`:

```
--dpi-desync=fakedsplit
--dpi-desync-split-pos=1
--dpi-desync-autottl
--dpi-desync-fooling=badseq
--dpi-desync-repeats=2
```

Оптимизирована для стриминга видео (4K, Shorts, Reels) с минимальными задержками.

## 📋 Требования

- **ОС:** Ubuntu 20.04+ / Debian 11+
- **Права:** root (sudo)
- **Сеть:** сервер должен работать как роутер (IP forwarding)
- **Зависимости:** устанавливаются автоматически

## 🌐 Настройка клиентов

Чтобы клиенты (телефоны, ноутбуки, ТВ) использовали Zalp:

1. Подключите их к Wi-Fi/Ethernet вашего сервера
2. В настройках сети укажите:
   - **Шлюз (Gateway):** IP вашего сервера
   - **DNS:** IP вашего сервера (или любой публичный DNS)

Пример для роутера:

```
Шлюз: 192.168.1.50
DNS: 192.168.1.50
```

## 🎮 Поддержка консолей (Xbox, PlayStation)

Для Xbox и PlayStation рекомендуется настроить **прямое подключение** к основному роутеру (шлюз = основной роутер), чтобы избежать Double NAT.

## 🗑️ Полное удаление

```bash
sudo ./uninstall.sh
```

Скрипт удалит:
- Каталог `/opt/zalp` (движок + конфиги)
- Systemd-сервис `nfqws`
- Cron-задачу Doctor
- Команды управления `zalp-*`
- Логи `/var/log/zalp-*.log`
- Правила NFQUEUE в iptables/ip6tables

Что **НЕ** трогает (намеренно):
- IP forwarding в `/etc/sysctl.conf`
- Базовый NAT и FORWARD (роутинг работает)
- Сетевые интерфейсы

## 🐛 Troubleshooting

### Обход не работает

1. Откройте `sudo zalp` → пункт 2 (Диагностика)
2. Если стратегия устарела, выберите пункт "Тестирование (Blockcheck)" для подбора новой
3. Примените новую стратегию и выполните `sudo zalp restart`

### Нет интернета после установки

1. Выполните `sudo zalp stop`
2. Если интернет появился, проблема в стратегии
3. Запустите `sudo zalp test` для подбора рабочей

### Mihomo не отвечает

```bash
sudo mihomo-test
sudo mihomo-restart
```

### TV Fix не работает

```bash
sudo fix test
# Проверьте, что MAC-адрес ТВ совпадает с прописанным в скрипте
```

### Переустановка

```bash
sudo ./restore.sh
```

Это полностью очистит систему и переустановит Zalp без разрыва интернета.
