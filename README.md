# 🛡️ Zalp v5.0 — Умный обход DPI и управление сетью

**Zalp** — это комплексная, модульная система обхода DPI-блокировок и управления сетевым трафиком на базе [zapret](https://github.com/bol-van/zapret), оптимизированная для домашнего сервера или роутера. В версии 5.0 система объединяет в себе обход DPI, прозрачный прокси (Mihomo), исправление маршрутизации для Smart TV и встроенную диагностику.

## ✨ Возможности
- 🚀 **Обход DPI**: YouTube, Instagram, Facebook, Threads и другие сервисы.
- 🩺 **Zalp Doctor**: Автоматическое самолечение и мониторинг каждые 5 минут.
- 🔄 **Горячая замена**: Переустановка и обновление без разрыва интернета.
- 🎛️ **Единая консоль `zalp`**: Управление всеми модулями из одного меню.
- 🌐 **Модуль Mihomo**: Встроенная поддержка прозрачного прокси (VLESS, Trojan, Shadowsocks и др.).
- 📺 **TV Fix VPN**: Автоматический прозрачный VPN для Smart TV (LG, Samsung) без настройки на самом телевизоре.
- 🧪 **Встроенный Blockcheck**: Автоматический подбор рабочих стратегий обхода для вашего провайдера.
- 📦 **Самообновление**: Следит за релизами на GitHub и обновляется в один клик.

## 🚀 Быстрый старт

### Установка
```bash
git clone https://github.com/MamBoota/Zalp.git
cd Zalp
sudo ./install.sh

Установщик предложит настроить базовый обход DPI, а также опционально установить Mihomo и TV Fix.
Единая консоль управления
Просто введите в терминале:
```bash
sudo zalp

Откроется интерактивное меню со статусом всех систем, управлением DPI, прокси, ТВ и диагностикой.
Команды управления
Все команды теперь объединены под одним интерфейсом zalp:

Команда sudo zalp | Описание Интерактивная консоль управления
Команда sudo zalp start | Описание Запустить обход DPI
Команда sudo zalp stop | Описание Остановить обход DPI
Команда sudo zalp restart | Описание Безопасный перезапуск (с проверкой сети)
Команда sudo zalp status | Описание Краткий статус всех модулей
Команда sudo zalp doctor | Описание Ручной запуск самолечения
Команда sudo zalp mihomo | Описание Меню управления прокси Mihomo
Команда sudo zalp tvfix | Описание Меню управления прозрачным VPN для ТВ
Команда sudo zalp test | Описание Запуск встроенного blockcheck.sh
Команда sudo zalp restore | Описание Полная очистка и горячая переустановка

🔧 Конфигурация
Основные файлы находятся в /opt/zalp/:
domains.txt — список доменов для обхода DPI.
domains-exclude.txt — исключения (например, локальные сервисы или 1С).
Стратегия обхода настраивается в /etc/systemd/system/nfqws.service (по умолчанию оптимизирована для 4K-стриминга с минимальными задержками).

🐛 Troubleshooting
Обход не работает?
Откройте sudo zalp → пункт 2 (Диагностика).
Если стратегия устарела, выберите пункт "Тестирование (Blockcheck)" для подбора новой.
Примените новую стратегию и выполните sudo zalp restart.

Нет интернета после установки?
Выполните sudo zalp stop.
Если интернет появился, проблема в стратегии. Запустите sudo zalp test для подбора рабочей.
